## 🏛️ Key Features

### 1. Duolingo-Style Sanskrit Learning (`/learn`)
- **Gamified Progress Metrics**: Live Level calculations (`Level 1 — Sanskrit Beginner` up to `Level 5 — Sanskrit Master`), daily consecutive study streaks, XP counters, and course completion gauges.
- **Sequential Stepped Path**: Visual vertical learning path with alternating nodes representing *Completed* (golden checkmark), *Active/Current* (pulsing golden halo), *Available*, and *Locked* lessons.
- **7 Diverse Interactive Exercise Formats**:
  1. **Match the Meaning**: Multiple-choice vocabulary comprehension.
  2. **Select Correct Sanskrit Word**: Audio-previewed Devanagari identification.
  3. **Complete the Sentence**: Contextual fill-in-the-blank with grammatical note.
  4. **Match Pairs**: Interactive two-column card matcher pairing Sanskrit terms with English translations.
  5. **Arrange the Words**: Tap and assemble sentence tokens into syntactically valid Sanskrit (SOV order).
  6. **Translate the Sentence**: Natural English translation selection.
  7. **Learn Through Images**: Visual symbol and icon cues.
- **Immediate Audio-Visual Feedback**: Encouraging feedback alerts, acoustic chime chords, celebratory canvas particle explosions upon lesson completion, and review options.

### 2. Sanskrit Knowledge Explorer (`/explorer`)
- **Two-Column Split Layout**:
  - **Left Panel**: Curated passages from the *Bhagavad Gita* (2.47), *Isha Upanishad* (1.1), *Rigveda* (10.191.2 *Samgacchadhvam*), *Hitopadesha*, *Aryabhatiya* (place-value notation), and *Charaka Samhita* (definition of holistic life).
  - **Interactive Word-by-Word Tokens**: Clicking any word in the Devanagari text highlights it and syncs with the analysis engine.
  - **Comprehensive Grammar Explorer**: Analyzes Subject (*Kartṛ*), Verb (*Kriyā* / *Lakāra*), Object (*Karman*), Case Inflections (*Vibhakti*), and Sandhi/Samasa compounds.
  - **Complete Word-by-Word Glossary Table**: Full tabular view of every term in the passage.
  - **Digital Gurukul AI**: Inquire about practical workplace ethics, linguistic roots, or Sandhi rules with context-aware responses citing traditional commentaries.
  - **Right Panel (`WordAnalysisPanel`)**: Large Devanagari token display, IAST transliteration, verified Dhātu root, grammatical case, contextual notes, audio recitation, and personal bookmarking.

### 3. A Word of Wisdom (`Nitya Śabdaḥ`)
- Featured daily word showcase on the home page with verified Paninian etymology, example sentences, and audio pronunciation.
- Date-deterministic rotation with forward and backward carousel navigation across 40+ curated terms.

### 4. The Living History of Sanskrit (`/history`)
- Chronological timeline spanning 6 major periods:
  1. **Early Vedic Traditions** (c. 1500–1000 BCE): *Rigveda*, oral transmission, and the *Padapatha* mnemonic preservation system.
  2. **Later Vedic Literature & Upanishads** (c. 1000–500 BCE): Shift to internal philosophical inquiry and early prose.
  3. **Panini & Classical Standardization** (c. 5th–4th c. BCE): The *Aṣṭādhyāyī* generative rule-based algebraic grammar.
  4. **Classical Literature & Intellectual Shastras** (c. 1st Millennium CE): Kalidasa, Aryabhata, Varahamihira, Charaka, and Sushruta.
  5. **Manuscripts & Commentaries** (c. 1000–1800 CE): Palm-leaf manuscripts, Bhashya commentaries, and the Kerala School of Mathematics.
  6. **Modern Era & Digital Humanities** (c. 19th c.–Present): Text-critical editions (BORI), digital archives (GRETIL), and computational Sanskrit linguistics.
- Detailed modal drawer with key texts, figures, linguistic markers, and direct links to passages in the Explorer.

### 5. Ancient Ideas, Modern Perspectives (`/knowledge`)
- Examines six disciplines: **Mathematics** (Pingala's binary algorithms and combinatorics, zero & place-value notation), **Astronomy** (Aryabhata's diurnal Earth rotation and relative motion), **Architecture** (Vastu geometry, fractal spires, and acoustic resonance), **Environmental Ethics** (Atharvaveda *Bhūmi Sūkta*), and **Medicine** (Charaka Samhita *Dinacharya* circadian cycles).
- **Academic Integrity**: Strictly distinguishes verified historical textual attestations from modern empirical sciences, avoiding pseudoscience.

### 6. My Progress & 3D Flashcards (`/progress`)
- Live dashboard displaying XP, streaks, accuracy %, and completed lessons.
- **Achievement Badges**: *First Steps*, *Word Collector*, *Grammar Explorer*, *Diligent Seeker*, *XP Centurion*, and *Wisdom Keeper* unlocking automatically via real user milestones.
- **Interactive Flashcard Mode**: 3D card-flip animations to review saved words, hear pronunciations, and earn bonus XP (*+5 XP* per mastered word).

## 📚 Curriculum Structure

```
Unit 1: First Steps (प्रथमः पादः)
  ├── Lesson 1: Introduction & Sacred Sounds (Om, Sanskrit etymology, greetings)
  ├── Lesson 2: Sanskrit Vowels (Svara: short, long, diphthongs, matras)
  └── Lesson 3: Sanskrit Consonants (Vyañjana: 5 vocal classes from throat to lips)

Unit 2: Everyday Sanskrit (व्यावहारिक-संस्कृतम्)
  ├── Lesson 1: Essential Nouns & Water (Jalam, Pustakam, Phalam, Vrksah)
  ├── Lesson 2: Sanskrit Numbers (Saṅkhyā: Ekam, Dve, Trini, Panca, Dasa)
  └── Lesson 3: Family & Relationships (Mātā, Pitā, Bhrātā, Mitram)

Unit 3: Build Simple Sentences (सरलवाक्यनिर्माणम्)
  ├── Lesson 1: Pronouns & Three Genders (Saḥ, Sā, Tat, Aham, Tvam)
  └── Lesson 2: Present Tense Verbs (Laṭ Lakāra: Pathati, Gacchati, Pibāmi)

Unit 4: Sanskrit Grammar (व्याकरण-प्रवेशः)
  ├── Lesson 1: Introduction to Vibhakti (The 7 Cases: Kartr, Karman, Karana...)
  ├── Lesson 2: The Sanskrit Dual & Number (Dvivacanam for natural pairs)
  └── Lesson 3: Basic Sandhi (Sound Junction: Savarna Dirgha Sandhi)

Unit 5: Wisdom Through Sanskrit (सुभाषित-गीता-सौरभम्)
  ├── Lesson 1: Timeless Subhashitas ("Vidya Dadati Vinayam...")
  └── Lesson 2: The Bhagavad Gita: Action & Mind (Chapter 2, Verse 47)
```

## 🚀 Quickstart & Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- `npm` (v9.0.0 or higher)

### 1. Clone the repository
```bash
git clone https://github.com/your-username/sanskrit-setu.git
cd sanskrit-setu
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the development server
```bash
npm run dev
```
Open your browser at **`http://localhost:5173`**.

### 4. Build for production
```bash
npm run build
```
The optimized, production-ready static bundle will be generated in `dist/`.

### 5. Preview production build
```bash
npm run preview
```
